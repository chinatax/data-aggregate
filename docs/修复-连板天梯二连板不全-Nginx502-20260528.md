# 修复连板天梯二连板不全 & Nginx 502

> 日期：2026-05-28
> 涉及文件：`StockDataService.java`、`nginx.conf`、`settings.json`

---

## 一、修复内容

### 1.1 `marketPrefix` 误判北交所 92xxx 为沪市

**文件**：[StockDataService.java:663](backend/dataagg-service/src/main/java/com/dataagg/service/service/StockDataService.java)

```java
// 修复前
if (code.startsWith("6") || code.startsWith("9")) return "sh";  // 92xxx 被误判为 sh!
if (code.startsWith("8")) return "bj";

// 修复后
if (code.startsWith("6")) return "sh";
if (code.startsWith("8") || code.startsWith("92")) return "bj";
```

**影响**：北交所 920012 等股票 K 线查询 `sh920012` 失败，`boardCount` 退化到 `1`。

### 1.2 深市代码遗漏 004xxx 段

**文件**：[StockDataService.java:651](backend/dataagg-service/src/main/java/com/dataagg/service/service/StockDataService.java)

```java
// 修复前
for (int i = 1; i <= 3999; i++) codes.add("sz" + String.format("%06d", i));

// 修复后
for (int i = 1; i <= 4999; i++) codes.add("sz" + String.format("%06d", i));
```

**影响**：sz004000~sz004999 段股票未被扫描，涨停股采集范围不完整。

### 1.3 Nginx 容器重启后 IP 变化导致 502

**根因**：nginx `proxy_pass http://backend:8081` 启动时一次性解析 DNS，缓存了旧 IP。后端容器重启后 IP 变化，nginx 仍往旧地址转发。

**永久修复**：[docker/nginx/nginx.conf](docker/nginx/nginx.conf)

```nginx
# 新增 resolver + 变量触发每次请求动态 DNS 解析
resolver 127.0.0.11 valid=30s;

location /api/ {
    set $backend_upstream backend:8081;
    proxy_pass http://$backend_upstream;  # 使用变量触发动态解析
    ...
}
```

### 1.4 关闭 extended thinking 避免 DeepSeek API 400

**文件**：`~/.claude/settings.json`

移除 `CLAUDE_CODE_EFFORT_LEVEL=max`。DeepSeek Anthropic 兼容层对 `thinking` block 回传存在格式差异，导致 `400 The content[].thinking in the thinking mode must be passed back to the API`。

## 二、部署步骤

1. 本地 `mvn -f backend/pom.xml clean package -DskipTests -q`
2. `scp jar → 112.124.35.167:/opt/dataagg/backend/dataagg-start.jar`
3. `cp jar → dataagg-start/target/` 对齐 Dockerfile COPY 路径
4. `docker build --no-cache -t dataagg-backend` + `docker restart dataagg-backend`
5. `docker exec dataagg-nginx nginx -t && nginx -s reload`（如 502）
