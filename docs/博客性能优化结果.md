## 图片优化

### 静态资源转 WebP

| 原文件 | 原始大小 | WebP | 减少 |
|--------|---------|------|------|
| tax-theory-cover.png | 435KB | 46KB | 89% |
| wechat-qr.png | 167KB | 46KB | 73% |
| alipay-qr.jpg | 239KB | 50KB | 79% |
| test-qrcode.jpg | 24KB | 8.5KB | 65% |
| **总计** | **841KB** | **152KB** | **82%** |

### 上传时自动优化

```
图片上传/AI生图
  ├── 原图保存 (如 abc123.png)          ← 详情页用
  ├── 缩略图 abc123_thumb.jpg (360px)   ← 列表页用，体积 ~5-15KB
  └── WebP版 abc123.webp               ← 可选，需服务器装 libwebp
```

- **缩略图**: Java ImageIO 原生生成，必定成功，质量 0.8
- **WebP**: 调用系统 `cwebp`，未安装时静默跳过
- **前端 `coverThumb()`**: 本站上传图片自动用 `_thumb.jpg`，外部 URL 保持原样
- **兜底**: `@error` 事件 — 缩略图 404 时自动回退原图
