## 二、个股日成交数据采集

### 建表 stock_daily_amount
```sql
trade_date, code, name, amount(成交额万), turnover_pct, volume_ratio,
float_market_cap(流通市值亿), industry, concept, region, top100_cs
UNIQUE KEY uk_code_date
```

### 数据源组合
- 腾讯 qt.gtimg.cn: f[37]=成交额, f[38]=换手率, f[45]=流通市值, f[49]=量比
- 东财 push2 f100/f102/f103 → 后改为腾讯stockinfo API(行业/概念/地区，批量慢未全量实现)
- 昨成交额(prevAmount): 查前一日记录, 无数据则往前倒推5天

### 去重+事务
```java
@Transactional
fetchAndCacheDailyAmounts() {
    dailyAmountService.deleteByTradeDate(tradeDate);
    dailyAmountService.saveBatch(entities);
}
// UNIQUE KEY uk_code_date DB兜底
```

## 三、首页改造: 三维看优 → 昨成交额排名

### 展示架构(两步)
```
15:30  采集行情 → stock_daily_amount(5509条)
         └─ 全量计算top100上榜次数 → 写 top100_cs 列

00:00  取最新日 top200 → 清旧写新 stock_daily_display(200条)
         └─ 含 top100CS(上榜次数)
```

### 前端
- 标题: "昨成交额"
- 排序: amount DESC, 前200只
- 每只: `中际旭创（110）` + `市值15139亿 · 换手1.58% · 量比1.62 · 广东板块 · 电子Ⅱ`
- K线弹窗: 今年全部日K(250天)

### 三级缓存
```
Caffeine(L1/10min) → Redis stock:daily:display(L2/25h) → stock_daily_display(L3/200行)
```

### 上榜次数
- 日更: da_03_kline窗口函数 `ROW_NUMBER() OVER (PARTITION BY trade_date ORDER BY amount DESC)` 取前100
- 存储: stock_daily_amount.top100_cs
- Redis缓存2天
