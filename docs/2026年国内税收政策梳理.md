> 截至2026年5月 | 来源：国家税务总局、财政部公告  
> 整理日期：2026-06-07

## 一、增值税 — 最大变化：《增值税法》正式施行

**2026年1月1日起**，《中华人民共和国增值税法》+《增值税法实施条例》同步施行，增值税从暂行条例正式上升为法律。

| 时间 | 配套政策 | 要点 |
|------|---------|------|
| 1月 | 增值税优惠政策衔接事项公告 | 旧优惠如何过渡到新法 |
| 1月 | 进项税额抵扣等有关事项公告 | 抵扣范围明确、混合销售细化 |
| 1月 | 增值税征管事项公告 | 起征点标准等 |
| 1月 | 长期资产进项税额抵扣暂行办法 | 固定资产进项税处理 |
| 1月 | 增值税预缴税款管理办法 | 预缴规则更新 |
| 1月 | 出口业务增值税消费税退（免）税管理办法 | 出口退税流程 |
| 1月 | 增值税纳税申报有关事项公告 | 申报表格更新 |
| 3月17日 | 增值税应税交易销售额计算口径公告 | 销售额认定标准 |
| 4月1日 | 进口环节增值税优惠衔接公告 | 跨境进口税收处理 |

**关键变化**：
- **个人住房**：销售未满2年住房，增值税征收率 **5%→3%**
- **一般纳税人登记**：年销售额超标的纳税人（自然人、非经常性单位除外）强制登记，生效时间为超标的当期1日
- **进项税额抵扣**范围进一步明确，混合销售行为认定标准细化

### 小规模纳税人优惠（延续至2027年底）

- 月销售额 ≤10万（季度≤30万）：**免征增值税**
- 适用3%征收率的应税收入，减按 **1%** 征收
- 已开具3%普通发票无需作废，申报时直接享受减税
- 小规模纳税人跨区域经营**无需预缴增值税**

### 增值税区域优惠

- 民族地区、自贸区、重点产业园区：增值税即征即退税率可提至 **50%-80%**
- 4月13日：平潭综合实验区增值税消费税退税货物范围调整

## 三、企业所得税

### 小微企业优惠（延续至2027年底）

- 年应纳税所得额 ≤300万元 → 实际税负 **5%**
  - 计算：应纳税所得额 × 25% × 20% = 5%
- 超过300万元部分：全额按 **25%** 税率计税
- 申报即享，无需审批

## 七、税务监管与稽查

### 1. 欠税公告新规（2026年3月1日施行）

**国家税务总局令第61号**，替代原试行办法：
- 规范欠税公告行为
- 明确公告内容、程序及异议处理机制

### 2. 涉税专业服务信用评价管理办法（2026年起）

机构信用等级 **TSC1-TSC5** 五级：
- **TSC5** 级高信用机构：绿色通道、批量申报
- **TSC1-2** 级低信用机构：重点监管对象，业务从严

### 3. 2026年稽查十大重点领域

| 领域 | 风险点 |
|------|--------|
| 电商直播 | 隐匿收入、私户收款 |
| 成品油行业 | 变票偷逃消费税 |
| 虚开发票 | 无真实交易开票 |
| 税收洼地套利 | 空壳公司、过票 |
| 农产品收购 | 虚开发票 |
| 网络货运平台 | 虚假运单 |
| 股权转让 | 阴阳合同逃税 |
| 高收入人群 | 个税规避 |
| 房地产 | 土地增值税隐瞒 |
| 跨境交易 | 转让定价 |

### 4. 金税四期大数据监管

- **发票风险**：顶格开具、频繁作废红冲
- **资金风险**：公对私频繁转账、个人账户收款与经营规模不匹配
- **申报风险**：增值税与企业所得税收入差异过大、税负率异常偏低
- **合规红线**：发票、合同、资金流 **"三流一致"**

## 八、2026年政策趋势总结

| 方向 | 要点 |
|------|------|
| **增值税法治化** | 暂行条例→法律，配套文件密集落地（年内已发10+个公告） |
| **小微企业减负** | 增值税、所得税、"六税两费"全线延续至2027年底 |
| **消费税扩围** | 啤酒征收方式调整，申报表更新，后续可能继续扩围 |
| **科技创新支持** | 研发加计扣除、集成电路税收优惠、进口设备免税 |
| **消费刺激** | 离境退税优化、住房增值税降低 |
| **监管趋严** | 欠税公告法治化、信用分级、金税四期精准稽查 |
| **银税互动** | 3月、5月多部门联合深化，企业融资更便利 |
